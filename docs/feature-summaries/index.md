# Feature Summaries

Esta carpeta guarda resumenes cortos de ramas ya terminadas o conversaciones largas que conviene recordar.

Objetivo:

- Recuperar contexto sin releer conversaciones enteras.
- Saber que cambio una rama, por que y como se verifico.
- Mantener los docs principales limpios.

Reglas:

- Codex propone el resumen, pero el usuario lo valida antes de guardarlo.
- Un resumen no debe copiar el diff completo.
- Si algo pasa a ser contexto estable, tambien debe integrarse en `docs/project-context.md`, `docs/architecture-overview.md` o `docs/ai-workflow.md`.
- Nombre recomendado: `YYYY-MM-DD-nombre-rama.md`.
